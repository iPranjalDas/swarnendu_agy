[49] NTFS Drive D Git Repository Push Protocol (2026-09-26)
|- Invariant: NEVER attempt `git init` directly on /mnt/d/ or any DrvFs NTFS Windows mount — will fail with "chmod on .git/config.lock failed: Operation not permitted".
|- Correct NTFS Git Push Protocol (3 Steps):
   1. Create staging directory in WSL ext4: `mkdir -p ~/hotwheels-git-push` (or similar)
   2. Copy source files excluding build artifacts: `rsync -a --exclude=node_modules --exclude=dist --exclude='.git' /mnt/d/<PROJECT>/ ~/hotwheels-git-push/`
   3. Init, commit, and push from ext4: `cd ~/hotwheels-git-push && git init && git add . && git commit -m "..." && git remote add origin git@github.com:... && git push -u origin main`
|- Note: node_modules and dist are excluded from git tracking — only source code is pushed.
